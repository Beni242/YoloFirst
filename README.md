#  YOLO First try

## 📋 Summary
In this project, I built a real-time vehicle counting system using YOLO for object detection. The program detects cars passing through a video feed and counts them each time they cross a defined line — a practical example of applying computer vision to traffic monitoring.

## Features

- Real-time vehicle detection using YOLOv8
- Line-crossing logic to count cars accurately
- Visual overlay showing bounding boxes and live count
- Works on pre-recorded video files

## Tech Stack

| Tool | Role |
|------|------|
| Python | Core language |
| YOLOv8 (Ultralytics) | Object detection |
| OpenCV | Video I/O and frame rendering |
| cvzone | Bounding box overlays |
| NumPy | Coordinate processing |
